# anton_shell — Gravity UI + Vite

Простой шаблон приложения на Vite + React с использованием Gravity UI UIKit.

Запуск:

```bash
cd " /home/deldore/work prpjects/anton_shell"
npm install
npm run dev
```

Открыть в браузере: http://localhost:5173

Примеры использования компонентов находятся в `src/App.jsx`.
